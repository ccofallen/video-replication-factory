# 用重新生成修正人物身份

遵守 [当前生成规则](generation-policy.md)：画质数值≤1.0最多15秒，>1.0或未指定最多10秒；只按明确数值判断。身份不合格时重新生成受影响的完整视频窗，不以贴图或换脸覆盖修补候选。

1. 对照用户原始照片、当前候选与源演员，定位眼形、脸型、发型、肤色、转头或遮挡等具体错误，保存失败帧与本次候选SHA。衣服正确、静态导引正确不等于实际身份正确。
2. 核对实际上传顺序、Picture与源槽位绑定、身份资料覆盖和未知属性。Picture定义身份；Video定义原动作、镜头、场景和时序。只换脸的范围也通过模型重新生成整帧，不转去换脸覆盖工具。
3. 修改当前身份参考、导引、提示词或合法时钟，准备有实质差异的试窗。导引只输入模型，不能粘到候选帧上。局域网同服务依次执行，先恢复原prompt_id再提交新的已审批输入。
4. 重新生成整窗，保持其原owner、动作阶段和镜头边界。实际检查完整输出到末帧，眼睛、侧脸、手脸遮挡、衣袖、道具、字幕及接点按原尺寸核对；保留区间按原速完整验收。
5. 选择通过的新整窗替换对应生成窗，其余窗口保持。失败不升级质量证据，持续调整生成策略，不用蒙版、alpha、旧演员身体或照片贴片掩盖问题。

旧face_swap／face_detail覆盖修复入口已停用；既有影片与其历史证据保留原结论。新制作使用普通候选审核、原时间轴组装和最终完整验收，不用外部贴片成片绕过审核。
